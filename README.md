# TimeCue

Простой кью-плеер для Windows в духе QLab: таймкод **MTC** и **LTC** (выдача и приём), звуковые кью, выдача **DMX** по **Art-Net / sACN** и **OSC**-сообщений.

## Как получить TimeCue.exe

**Вариант 1 — GitHub собирает сам (как с APK для Web DMX).**
1. Создайте приватный репозиторий, например `timecue`, и загрузите в него все файлы из архива (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** → «Сборка TimeCue для Windows». Сборка запускается сама при каждой загрузке, вручную — кнопкой **Run workflow**.
3. Через 5–7 минут внизу страницы сборки появится артефакт **TimeCue-windows** — внутри `TimeCue.exe`. Рядом артефакт **screenshots** со снимками окон.

Сборка не выпустит exe, если не прошли тесты ядра или самопроверка интерфейса.

**Вариант 2 — собрать на своём компьютере.**
Поставьте Python 3.12 с python.org (галочка «Add python.exe to PATH»), распакуйте архив и запустите `build.bat`. Готовый файл — `dist\TimeCue.exe`.
Запустить без сборки: `run.bat` (первый раз поставит зависимости).

## Быстрый старт

1. **⚙ Настройки → Таймкод**: частота кадров и источник времени.
   - *Внутренние часы* — TimeCue сам ведёт время (мастер) и может выдавать MTC/LTC.
   - *Следовать за MTC / LTC* — время приходит от пульта, DAW или другого плеера; кью срабатывают по нему.
2. Добавьте кью: **+ Звук** (или перетащите файлы в окно), **+ DMX**, **+ OSC**.
3. В поле **Таймкод** справа впишите момент срабатывания или нажмите **⏱ Текущий**. Пустое поле — кью только по **GO**.
4. Сохраните шоу (Ctrl+S) — в файл `.tcshow` попадают кью и все настройки.

## Как ведут себя кью

- Кью с таймкодом срабатывают сами, когда время его проходит. Любую кью можно запустить кнопкой **GO** (пробел) — она стреляет выделенную кью и переходит к следующей.
- **Перемотка.** Звук подхватывается с нужного места, DMX восстанавливается по всем DMX-кью до этой точки (отключается в настройках).
- **Пауза/стоп** времени останавливает звук, запущенный по таймкоду. Звук, запущенный по GO, играет до конца или до **Esc**.

## Выходы и входы

| Что | Где настроить | Подсказка |
|---|---|---|
| MTC | Настройки → MTC | Для другой программы на этом же ПК нужен виртуальный порт **loopMIDI** |
| LTC | Настройки → LTC | Отдельный канал звуковой карты, уровень по умолчанию −10 дБFS, есть опережение в мс |
| Звук | Настройки → Звук | Карты с пометкой [WASAPI] — лучший выбор для многоканальных выходов |
| DMX | Настройки → DMX | Строка = вселенная: протокол, номер в сети, IP ноды, **сетевая карта** (если нода принимает только с определённого адреса) |
| OSC | Настройки → OSC | Именованные получатели «IP:порт», в кью выбирается имя |

Режим «Следовать за LTC» + включённый выход MTC = конвертер LTC → MTC (и наоборот).

## Формат времени

`01:00:05:12` — ЧЧ:ММ:СС:КК · `1:05:12` — Ч:ММ:СС · `2:30` — ММ:СС · `90` — секунды.
Для 29.97 drop-frame последний разделитель — `;`.

## OSC-аргументы

Через пробел: `5` — целое, `0.5` — дробное, `true`/`false` — логическое, `"текст с пробелами"` — строка. Явно: `i:5`, `f:5`, `s:5`.

## Горячие клавиши

Пробел — GO · Esc — стоп всего звука · F5 — пуск/пауза · F6 — стоп и в начало · Ctrl+T — текущий таймкод в кью · Ctrl+G — перейти к времени · Ctrl+D — дублировать · Delete — удалить · F1 — справка.

## Ограничения версии 1.0

- Видео не воспроизводится — только звук, DMX и OSC.
- ASIO не поддерживается (используйте WASAPI). Файлы лучше готовить в 48 кГц — тогда без пересчёта частоты.
- В режиме следования звук стартует по таймкоду, но не подтягивается под медленный дрейф внешних часов; при скачке времени перезапускается с нужного места.
